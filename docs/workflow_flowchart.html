图一：单视频主流水线（process_video）

flowchart TD
    A["输入：视频数据包
标题 / 简介 / ASR / OCR spans / 评论 / 帧图"] --> B["适配器读取
v1 schema 1.0.0 · v2 schema 1.0"]
    B --> V{"数据校验
引用 / 时间 / 路径 / 计数"}
    V -->|"不通过"| X1["视频标记 failed
错误写入 errors.jsonl"]
    V -->|"通过"| N["normalize → normalized.json"]
    N --> EV["证据库注册（确定性）
全局 ID = video::kind::local_id
OCR span 与底层记录同源分组"]
    EV --> WD["窗口切分（确定性）
6s 核心 + 1s 前后文 · 1Hz 采样 ≤8 图
Pillow 缩放 → derived_media/"]
    WD --> T1["文本提取 LLM
背景 / 时间文本 / 评论三批次分开发送
父评论仅作上下文"]
    T1 --> T2["输出超长 → 按记录边界拆半重跑一次
跨窗口去重"]
    T2 --> O1[("claims.jsonl
陈述 + 合法证据引用")]
    WD --> T3["视觉观察 LLM
按窗口发帧：帧 + ID + 时间戳
区分道路 / 界面 / 画面文字"]
    T3 --> O2[("observations.jsonl")]
    O1 --> EM["同源复述检测（embedding）
余弦 ≥0.90 → same_source 边
只标记不删除 · 失败跳过不阻断"]
    O2 --> MG["确定性合并事件簇
同类现象 + 间隔 ≤1s + 无剪辑疑点
剪辑疑点拆分并标记可能相关"]
    MG --> PF["embedding 预筛
视频级陈述只取 top-5 事件
时间重叠候选始终保留 · 筛除对落盘可追溯"]
    PF --> AL["LLM 对齐
supports / contradicts / possible_match
评论只做视频级候选关联"]
    O1 --> AL
    AL --> O3[("events.jsonl
事件 + 陈述关联 + 对齐状态")]
    O3 --> RV["审查 LLM
找证据缺口：issues + 补证请求"]
    RV --> RQ{"补证请求类型"}
    RQ -->|"补帧 / 原图分辨率
（自动可执行）"| RF["自动补证：ffmpeg 4Hz 原分辨率
事件中心 ±3s 补帧 → 重新观察
每事件最多一轮"]
    RF -->|"新观察并入事件"| O2
    RQ -->|"其余三类"| MAN["人工复核队列"]
    RV -->|"issues"| MAN
    O3 --> AT["归因 LLM
每事件 ≤3 个候选假设 + 空假设路径
支持 / 矛盾证据 · 反事实 · 缺失信息
verification_status 固定 unverified"]
    AT --> O4[("hypotheses.jsonl")]
    O4 --> RU["规则分级 + 业务校验（确定性）
三维度证据分级 · 归因不自动授予 high
违规 → 降级 insufficient_evidence
所有事件强制附加人工复核项"]
    RU --> OUT["输出
report.md · evidence_graph.json
review_queue.jsonl · summary.md（批量）"]
    EM -.->|"same_source 边"| OUT

图二：运行编排与支撑设施（run / batch / resume）

flowchart TD
    DOC["doctor 自检
离线 / --live 五项能力探测"] --> OK{"能力可用？"}
    OK -->|"是"| CMD
    OK -->|"否"| STOP["按提示配置 .env
（LLM_API_KEY / 端点）"]
    CMD["命令入口
run 单包 · batch 全量 · resume 续跑"] --> MODE{"运行模式"}
    MODE -->|"mock（默认）"| MOCK["MockLLMClient
确定性占位输出 · 不消耗预算"]
    MODE -->|"live（显式指定）"| LIVE["OpenAI 兼容客户端
阿里云百炼 qwen3.8-flash · SSE 流式
LLM_ENABLE_THINKING 全局控思考"]
    MOCK --> PIPE
    LIVE --> PIPE["process_video 主流水线
（见图一）"]
    PIPE --- FRAME
    subgraph FRAME["每个 LLM 任务的执行框架"]
        ST["state.sqlite 任务状态机
成功 → resume 零重复调用
单任务失败不阻断其他任务"]
        CACHE["响应缓存 cache.sqlite
键含提示词哈希 + 模型
换模型须开新运行"]
        BUD["预算 / 节流 / 守卫
预算尽 → paused_budget
连续 3 个任务 429 → 自动暂停
401 → 停止 · Ctrl+C → 存进度退出"]
        FIX["失败自救
重试 + Retry-After 退避
一次 JSON 格式修复 · 截断标记"]
    end
    PIPE --- EMB["embedding 客户端
官方百炼 text-embedding-v3
live 启动探测失败 → 整轮禁用并明示
mock 自动降级确定性哈希向量"]
    PIPE --> OUT2["运行产物
run_manifest.json · config_snapshot.json
usage.jsonl / errors.jsonl · summary.md"]
    EVAL["evaluate 对照标注
stability 3 次独立采样
crossvideo 跨视频聚类"] -.->|"对已有 run_id 分析"| OUT2
